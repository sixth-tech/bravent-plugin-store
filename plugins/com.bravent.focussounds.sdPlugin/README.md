# Bravent Ambient Sounds v1.0.9

Ambient focus-sound plugin for Bravent Rhythm Deck.

## Included sounds

- Raining
- Fire
- Forest
- Lake
- Sea Shore

## Controls

### Key action (`Ambient Sounds Key`)

- Tap: play / pause
- Hold: switch to next sound

### Knob action (`Ambient Sounds Knob`)

- Press: play / pause
- Spin while paused: switch sound
- Spin while playing: adjust Ambient Sounds volume only, without changing the computer master volume

## Settings

- Sound type
- Play source (output device)
- Auto repeat (loop)
- Timer in minutes (`0` = no timer)
- Beep at end
- Custom volume
- Background color
- Background opacity
